Bus Ticket Booking Application

The Bus Ticket Booking System is a web application that bridges passengers and bus operators. Operators can manage routes, schedules, and capacity through an admin dashboard.

Embedded Systems
AI-Based Fire-Fighting Robot with Smoke Extraction & Filtration

A robot designed to extinguish fires and filter poisonous air, developed using Arduino UNO and NodeMCU microcontrollers. Integrated with an ultrasonic sensor for navigation, a flame sensor for fire detection, and a smoke/gas sensor for hazard identification. Features motor-driven wheels, a motor pump for water supply, and a DC fan with active carbon filter. Operates in both manual and automated modes.
